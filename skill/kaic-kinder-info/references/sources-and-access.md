# 출처·설정·부분 실패

## 키와 대상 식별

| 설정/출처 | 용도와 한계 |
|---|---|
| KINDER_API_KEY | 기본현황·대상 유치원 식별 및 공시 API. 신규/강제 재조회에는 유효 키 필요 |
| NEIS_API_KEY | 병설 모초등학교 학사일정·급식 보조 조회에만 사용 |
| SCHOOLINFO_API_KEY | 병설 모초등학교 학교알리미 정보에만 사용 |
| CHILD_BIRTH_YM | 기존 아이 설정으로 target 계산; 조회를 위해 저장할 필요는 없음 |
| HOME_LATLNG | 기존 위치로 거리·경로를 요청한 경우 사용; 정확한 값 노출하지 않음 |
| 유치원알리미 웹 | 혼합반·원비·시정명령·운영시간·보건환경·재정. 별도 웹 키는 없지만 CLI는 대상 기본현황 조회를 먼저 함 |
| OSRM / 공식 교통 자료 | 자차 경로/예상시간과 공식 사고다발지. 출발·목적 좌표를 외부 서버에 전달하며 실시간 교통 미반영 |
| 학교안전지원시스템 | 공개 등록과 API 버스 정보를 교차. 별도 서비스 키가 없어도 접근 실패 가능 |

공개 출처에 별도 인증키가 없는 것과 **CLI 전체가 keyless인 것**은 다르다.
`profile --web`, health/finance/traffic/bus 등은 이름→대상 식별에 기본 API를 사용한다.
유효한 캐시로 식별되는 경우와 새 API 요청을 구분하고, 키가 없다는 이유로 SQLite 직접 쓰기나 임의의 키를 만들지 않는다.
선택 키/출처가 실패하면 그 부분만 미확인으로 표시하고 확보한 요청 결과를 제공한다.

## 설치·설정이 필요한 경우

- 기존 도구 경로·`kinderinfo.py --version`·실제로 응답하는 Python을 먼저 확인한다. CLI는 Python 3.9 이상/표준 라이브러리, MCP에만 선택 패키지 mcp가 필요하다.
- 설치 요청 때만 사용자 지정 위치에 kaicot 포크를 설치한다. API 신청은 [공식 Open API 안내](https://e-childschoolinfo.moe.go.kr/openApi/openApiIntro.do)를 따른다. 승인 방식·키 형식은 현재 안내로 확인하며 고정된 형식을 추정하지 않는다.
- 새 `.env`는 기존 파일이 없을 때만 예시에서 준비한다. 이미 있는 파일 전체를 복사/교체하지 않는다.
- 설정 이름은 `.env.example`을 따르고, 키·개인 값은 표시하지 않는다. 사용자에게 키를 대화에 반드시 붙여넣도록 요구하지 않는다.
- 아이 나이가 주어지면 `--age N`으로 조회할 수 있다. 생년월 저장은 사용자가 개인화 설정을 요청한 경우에만 한다.
- MCP 등록/설정 변경은 설치 요청에 포함된 범위에서 수행한다. 기존 세션을 재시작하거나 다른 MCP를 변경하지 않는다.

## 조회의 부수효과와 명시적 변경

일반 조회에도 API/웹/경로 캐시 및 새 공시 확인 기록이 생길 수 있다. 완전히 무변경인 명령이라고 부르지 않는다.
이는 home·pick·생년월 설정처럼 개인 프로필을 지속 저장하는 명령과 구분한다.

- home은 네이버 링크를 외부 조회해 좌표를 추출하고 `.env`에 저장한다. 새 위치 조회/저장의 용도를 설명하고 요청 범위를 확인한다.
- 경로 요청은 집/유치원 좌표를 OSRM에 보낸다. 좌표 제공을 금지한 요청에서는 호출하지 않는다. 저장된 위치가 있어도 무관한 조회에서 자동으로 경로를 덧붙이지 않는다.
- 후보 저장·삭제는 pick, 파일 출력은 report --out, 버스 자료 가져오기는 bus-import의 명시 요청 범위에서만 한다. 기존 파일·후보·자료를 임의로 대체하지 않는다.
- refresh는 캐시를 삭제/갱신하는 명령이다. 보통 최신 조회는 지원되는 해당 명령의 --fresh로 시작하며, 전체 출처 갱신이 필요할 때만 --all을 사용한다.
- discover는 코드표 저장과 여러 API 요청을 동반한다. 결과 0곳만으로 5~10분 전수 스캔을 자동 실행하지 않는다.

## 실패·최신성·출처 표시

- 인증 거부, 원 공시 점검 중, 빈 결과, 웹 구조 변경, 경로/버스 출처 실패를 구분한다. 한계를 숨기거나 실패를 0으로 변환하지 않는다.
- fresh는 각 구현의 캐시 재조회 옵션이다. 과거 차수·영구 경로 캐시·선택 출처 모두가 새로 검증됐다고 보장하지 않는다.
- 자료 기준일·공시 차수·학년도는 응답에서 확인한다. 재조회 시각이나 XLSX 가져온 시각을 원자료 기준일로 사용하지 않는다.
- 명칭이 같은 유치원은 지역/주소로 대상을 대조한다. 시정명령 등의 다른 기관 자료를 섞지 않는다.
- 원문 구조가 달라졌다면 원본 링크를 제공하고 관련 파서만 점검한다. source status/help 통과는 실제 API 왕복 성공이 아니다.
- 반복 실패는 원인을 보고하고 확보한 부분 결과를 제공한다. 지침 유지보수 때문에 live selftest·캐시 삭제·공시 전수 수집을 수행하지 않는다.

## 공개 범위

키·집 좌표·아이 생년월·개인 후보 및 운영시간 검증 파일은 공개 Git에 포함하지 않는다.
차량번호·운영자/교직원 이름을 답변·로그에 노출하지 않는다. 원본 JSON/XLSX를 그대로 공유하지 않는다.
후보 브리핑을 외부 업로드하거나 공개 배포하는 행위는 로컬 저장 요청에 포함되지 않는다.
