# 유치원 입학 일정과 준비

유치원 후보를 실제 지원으로 이어가기 위한 공식 일정·절차를 안내한다.
입학 접수 대행이나 어린이집 검색으로 범위를 넓히지 않는다. 이 안내는 CLI/MCP에 새 기능이 생겼다는 뜻이 아니다.

## 요청에 맞는 공식 안내 확인

- 이미 알려진 희망 학년도·지역·연령·후보를 사용한다. 일정만 묻는 요청에 아이의 정확한 생년월이나 API 키를 요구하지 않는다.
- [유보통합포털](https://www.childinfo.go.kr/)·[유치원입학](https://enter.childinfo.go.kr/), 해당 시도교육청의 해당 학년도 유아모집 공고, 지원 유치원의 모집요강을 확인한다. SNS·블로그는 공식 원문을 찾는 단서로만 사용한다.
- 접수하는 달력연도와 입학 학년도를 구분한다. 전국 서비스 개시 안내를 모든 유치원의 일반모집 접수일·마감일로 확대하지 않는다. 우선·일반·추가모집별 대상, 접수·발표·등록 기간과 시각을 관련 공식 공고에서 확인한다.
- 우선모집 자격·증빙서류·지원 가능 개수는 해당 학년도와 기관의 기준으로 확인한다. SNS 댓글의 자격 목록을 전부라고 단정하거나 보호자의 자격을 추정하지 않는다.
- 답변에는 요청에 필요한 일정·준비할 일·공식 링크·공고일·확인일을 담는다. 세부 공고를 확보하지 못한 부분은 미확인으로 남기고 확인한 전국 안내까지 제공한다. 과거 일정을 연도만 바꾸어 재사용하지 않는다.

## 저장·신청·결과를 구분

- 도구의 `pick`은 이 PC의 로컬 후보 저장이다. 포털의 찜 목록과 자동으로 동기화하거나 원서를 제출하지 않는다. 포털 찜하기를 묻는 요청으로 `pick`을 실행하지 않는다.
- 포털 찜하기는 관심 기관 저장이다. 별도의 실제 신청과 신청 상태 확인이 필요하며, 신청·접수와 선발·등록 완료도 서로 다른 단계다. 찜한 순서나 시점이 선발 우선권을 보장한다고 안내하지 않는다.
- 안내된 선개통·개편은 시행 전에는 예정으로 표시한다. 공고 확인을 실제 개통 화면·개인 계정 상태 검증으로 보고하지 않는다. 행정정보 연계도 모든 서류의 면제나 자동 제출 완료로 해석하지 않는다.
- 기존 어린이집 입소대기의 유지·재신청 여부는 유치원 모집 일정으로 판단할 수 없다. 공식 어린이집 안내에서 확인하도록 연결하고 계정 상태를 추정하지 않는다.
- 사용자는 공식 포털에서 로그인·자녀등록·정보제공 동의·신청 상태를 직접 확인한다. 안내를 위해 가족관계증명서·주민등록번호·인증정보를 수집하지 않는다. 알림서비스 소개를 알림 신청·자동 모니터링 요청으로 해석하지 않는다.
