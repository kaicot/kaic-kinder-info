# 공시와 보조 출처 해석

## 연령·모집·혼합반

- 명시된 연령·희망 학년도를 기준으로 답한다. current/default/target 계산과 사용자의 지정 연도가 다르면 기본값으로 덮어쓰지 않는다.
- Open API의 혼합반 수만으로 구성 연령을 알 수 없다. 해당 연령 전용반이 없고 혼합반이 있으면 현재 웹 학급표를 확인하고, 실패 시 구성 미확인 후보로 유지한다.
- 혼합반 정원·현원은 포함 연령 전체 합계다. 만3세 등 한 연령의 정원/모집인원으로 나누거나 전용반 0명을 미모집으로 읽지 않는다.
- 인가정원·편성정원·재원 현원·신규 모집인원은 서로 다르다. 다음 학년도 모집요강/지원 개수/우선모집 조건은 도구 공시가 아니라 해당 학년도 [유보통합포털 유치원입학](https://enter.childinfo.go.kr/) 및 유치원 공식 안내로 확인한다.
- 지정한 후보가 많아도 입학 지원 개수 규칙을 가정해 자동 축소하지 않는다. 도구 출력 제한은 분할 조회로 처리할 수 있다.

## 지표와 추이

- 충원율은 공시된 원아수/정원의 비율이다. 분모의 정원 종류와 차수를 표시하고 인기·교육 품질 점수로 확정하지 않는다.
- 교사 근속 평균은 공시 구간의 중간값 가중 추정치다. 1년 미만 비율이나 그 변화만으로 이직이 잦다/안정화됐다/교사를 대거 교체했다고 단정하지 않는다.
- 학급당 원아 수는 규모 지표이지 실제 교사 배치·개별 돌봄·교육 품질의 측정값이 아니다. 교직원·방과후 인력을 확인했다면 별도 사실로 설명한다.
- 재정 규모·원비만으로 품질을 순위화하지 않는다. 출력에 있는 인기/안정 같은 휴리스틱 표현을 검증된 사실로 반복하지 않는다.
- trend는 같은 정의와 차수의 변화를 보여준다. 시작↔끝 변화, 결측과 중간 차수 패턴을 구분한다. diff는 두 차수 차이이지 변화 원인 분석이나 상시 모니터링이 아니다.

## 운영시간·방학·모초등학교

- 전체 운영 외곽 범위를 정규수업 시간으로 해석하지 않는다. hours로 정규·일반 방과후·조기·저녁·방학을 구분하고 출처·근거 학년도를 함께 표시한다.
- 이전 학년도 계획은 희망 학년도의 참고값이다. 새 계획 미확보를 해당 운영이 없다는 뜻으로 바꾸지 않는다.
- 병설 모초등학교의 NEIS 일정·급식/학교알리미 정보는 유치원 자체의 확정 일정·운영/보건 상태가 아니다.
- 수업일수·방과후 운영일수·실제 등원 가능일은 구분한다. 특정 사례의 일수 차이와 방학 길이를 모든 병설/사립에 일반화하지 않는다.
- 법정 일수·수업시간이나 특정 연도 모집 규칙을 안내해야 할 때만 현재 공식 기준을 확인한다. 지침의 과거 고정 수치를 법률/일정으로 쓰지 않는다.
- `-`·빈 셀·점검 중·출처 실패는 0/미운영과 다르다. 원비 0도 단위·기준 월/연도·지원 포함 범위를 확인한다. 비용 표의 `-`는 해당 표의 정의와 학급 구성을 확인한 뒤 해석한다.

## 접근성·교통·버스

- 직선거리, 자차 도로거리/시간, 도보거리/시간을 구분한다. OSRM 자차 경로를 도보 통학 경로로 바꾸어 말하지 않는다.
- 경로는 캐시된 OpenStreetMap/OSRM 자료와 비실시간 추정이다. 등원 시간대 실측이나 최신 일방통행·정차 여건이 검증됐다고 하지 않는다.
- 우회율/거리만으로 위험을 판정하지 않는다. traffic은 실제 자차 경로와 공식 사고다발지 폴리곤의 교차이며, 0곳은 안전 인증이나 무사고 보장이 아니다.
- 정차·승하차 여건은 주소만으로 추정하지 않는다. 요청에 맞는 로드뷰/현장 근거를 구분하고, 방문 질문 목록은 요청 때만 추가한다.
- 통학버스는 출처별 등록/운행 표시를 나란히 확인한다. 한 출처 누락을 미운행, 등록차량 수를 노선/정류장/등원시간 보장으로 해석하지 않는다.

## 시정명령과 답변

- 동일 기관인지 대조한 뒤 내용·처분 시점·확인된 개선 여부를 출처와 함께 설명한다. 이력만으로 후보를 자동 배제하거나 현재 위반 중이라고 단정하지 않는다.
- 사용자 선택 기준에 맞춰 비교한다. 공시만으로 가장 좋은 유치원이나 교육 품질의 종합 순위를 만들지 않는다.
- 답변에는 필요한 수치·단위·출처·자료연도/차수와 미확인을 담고, 공시 사실·계산/추정·판단을 구분한다. 표 전체를 자동 첨부하지 않는다.
- 후기 요청은 접근 가능한 공개 정보만 별도로 확인하고 공시와 섞지 않는다. 일부 후기/동명이름을 전체 학부모 만족도로 일반화하지 않는다.
