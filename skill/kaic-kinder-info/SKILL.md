# KAIC Kinder Info

공시 사실과 추정·미확인을 구분하여 사용자가 요청한 조회·비교를 끝낸다.
이미 알려진 지역·연령·후보는 재사용하고, 대상이 모호할 때만 묻는다. 일반 조회 때문에 후보를 저장하거나 모든 출처를 추가하지 않는다.

## 필요한 문서만 읽기

아래 참고 파일은 이 SKILL.md와 함께 설치된다:

| 상황 | 참고 문서 |
|---|---|
| 명령·옵션 선택, MCP에 없는 기능 | [명령 안내](references/commands.md) |
| 설치·인증·출처 실패·위치 제공·파일 저장 | [출처와 접근](references/sources-and-access.md) |
| 지표·혼합반·운영시간·추이·교통 해석 | [해석 기준](references/interpretation.md)의 관련 절 |

도구 저장소는 `{{TOOL_DIR}}`이다. 실행 전 `kinderinfo.py`가 있는지 확인한다.
MCP가 등록되어 있으면 요청에 맞는 도구를 사용하고, 지원하지 않는 옵션은 검증한 Python 실행 파일로 CLI를 호출한다.
설치 스킬 폴더에 CLI 코드가 있다고 가정하지 않는다. 저장소 유지보수 시에는 도구 경로의 AGENTS.md를 읽는다.

## 요청 → 진입점

| 요청 | 명령/옵션 |
|---|---|
| 지역·연령·설립유형 검색 | `search <지역> --age 3|4|5`, 필요 시 `--estab`, `--name`, `--limit` |
| 한 곳 상세 / 혼합반·원비·시정명령 | `profile <지역> <이름>` / `--web` |
| 후보 비교 / 브리핑 | `compare` / `report`; 명시된 후보와 기준을 유지 |
| 정규·방과후·돌봄 시간 | `hours`; 지정 학년도는 `--year YYYY` |
| 추이 / 두 차수 변화 | `trend` / `diff`; 저장 후보가 없어도 인자로 조회 가능 |
| 병설 학사일정 / 모초등학교 정보 | `schedule` / `mother-school`; 유치원 자체 확정값과 구분 |
| 보건·환경 / 예산·결산 | `health` / `finance` |
| 자차 경로 안전 / 통학버스 | `traffic` / `bus`; 거리만은 `search --road` |
| 출처·지역·원자료 상태 | `sources`, `regions`, `raw`, `bus-status` |
| 코드 탐색·캐시 갱신·후보/위치 저장·버스 자료 가져오기 | `discover`, `refresh`, `pick`, `home`, `bus-import`; 아래 변경 경계 적용 |

검색·상세의 최신 조회는 MCP `fresh=True` 또는 CLI `--fresh`를 사용한다.
이것은 캐시 재조회이며 새 공시/새 학년도 확정 보장이 아니다. 출처별 캐시·원문 시점을 확인한다.
MCP에 없는 `--out`, `--year`, `--fresh` 등은 **해당 도구에 실제로 없는 경우에만** CLI로 전환한다.

## 틀리기 쉬운 경계

- 지정 연령은 `--age`, 학년도 지원 명령은 `--year`로 반영한다. `--target`은 기존 아이 설정과 계산 기준이 요청에 맞을 때만 사용하고 `--age`와 동시에 붙이지 않는다. 없다고 생년월 저장을 기본 제안하지 않는다.
- 혼합반의 정원·현원은 포함 연령 전체 합계다. 전용반 0명이나 구성 확인 실패를 미모집으로 단정하지 않는다. 현재 공시 정원은 다음 학년도 모집인원이 아니다.
- 충원율·근속 구간·학급당 원아 수만으로 인기·교사 이직 원인·교육 품질을 확정하지 않는다. 근속 평균은 구간 중간값을 이용한 추정치다.
- 전체 운영범위와 정규·방과후·돌봄 시간을 구분한다. 이전 학년도 계획과 모초등학교 일정은 참고자료다. `-`·누락·조회 실패를 0/미운영으로 바꾸지 않는다.
- 공개 웹·교통·버스 **출처 자체**에 별도 키가 없더라도, CLI의 대상 유치원 조회에는 유치원알리미 API가 필요할 수 있다. 선택 출처 실패는 확보한 결과와 구분해 보고한다.
- 직선거리와 자차 도로거리·시간을 구분한다. OSRM은 실시간 교통이 아니며 사고다발지 0곳도 안전 인증이 아니다. 경로 조회는 출발·목적 좌표를 외부 서비스에 보낸다.
- 시정명령은 내용·시점·확인된 개선 여부로 설명하고 자동 배제하지 않는다. 모집요강·경쟁률·노선은 이 도구의 공시만으로 확인되지 않으며 해당 학년도 공식 안내를 별도로 확인한다.

## 변경·개인정보 경계

후보 언급만으로 `pick`을 실행하지 않는다. `home`·생년월 설정·`pick`은 로컬 저장 요청을 확인한 경우에만 수행한다.
거리/경로를 요청받았을 때 기존 위치를 필요한 범위에만 쓰고, 새 집 위치를 외부 조회·저장할 때 용도를 설명한다.
파일 저장은 요청된 경로의 `report --out`으로 수행하며 기존 파일을 임의로 덮어쓰지 않는다.
`refresh --all`·후보 삭제·전수 코드 탐색은 보통 조회/스킬 업데이트의 자동 후속 단계가 아니다.
버스 XLSX를 가져와 달라는 요청에서는 파일을 확인한 뒤 `bus-import`와 `bus-status`로 결과를 확인한다.
키·정확한 생년월·집 좌표·차량번호·개인 이름은 답변/로그/공개 저장소에 노출하지 않는다.
방문·전화 질문은 명시 요청 때만 `report --questions`로 추가한다.

## 완료 보고

질문에 필요한 결과와 출처 링크·공시 차수/자료연도·요청 학년도를 함께 설명한다.
사실·추정·출처 실패·미확인을 분리하고, 재조회 시각을 원자료 기준일로 대신 쓰지 않는다.
조회 계획·CLI 도움말·문법 검사만으로 실제 조회 성공이라고 하지 않는다.
