# kaic-kinder-info — 유치원알리미 조회 도구

교육부 유치원알리미 공시 데이터(14개 항목)를 조회하는 CLI. 파이썬 표준 라이브러리만 쓰므로
별도 설치가 필요 없다.

도구 경로: `{{TOOL_DIR}}`

## 실행 방법

MCP 도구(`kaic-kinder-info`)가 등록돼 있으면 그것을 쓰고, 없으면 CLI를 직접 실행한다.

```
python {{TOOL_DIR}}\kinderinfo.py <명령> ...
```

| 명령 | 용도 | 예시 |
|---|---|---|
| `search <지역>` | 목록 + 핵심 수치 표 | `search "서울 강남구" --age 3` |
| `profile <지역> <이름>` | 1곳 전체 공시 종합 리포트 | `profile "서울 강남구" 강남유정` |
| `compare <지역> <이름들>` | 비교표 | `compare "서울 강남구" "가나,다라"` |
| `raw <엔드포인트> <지역>` | 원본 JSON | `raw basicInfo2 11680` |
| `regions` | 저장된 지역 코드 목록 | |
| `discover <시도>` | 새 시도 코드 탐색(최초 1회) | `discover 경남` |

- 지역: `서울`(시도 전체), `"서울 강남구"`, `강남구`(유일할 때), `11680`(코드, 가장 빠름)
- search 옵션: `--age 3|4|5` `--target` `--estab 공립|사립` `--name <부분명>`
  `--sort name|size|fill` `--limit N`
- 공통: `--fresh`(7일 캐시 무시), `--json`(원자료)
- 출력이 마크다운이므로 그대로 인용하거나 요약해서 답하면 된다.

## 사용자 아이에 맞춰 찾기

`.env`에 `CHILD_BIRTH_YM=YYYY-MM`이 설정돼 있으면 **`--target`을 쓰는 것이 가장 정확하다.**
입학 학년도와 연령반을 자동 계산해(만3세반 = 출생연도 + 4) 해당 연령반만 걸러준다.

설정돼 있지 않은데 사용자가 아이 나이를 말하면, 생년월을 `.env`에 저장해 두자고 제안하거나
`--age N`으로 직접 지정한다. 유치원은 만 3~5세를 받는다.

## 결과 해석 가이드

- **충원율**(원아수/인가정원): 높으면 인기, 지나치게 낮으면(30% 미만) 이유를 확인할 만하다.
- **교사 근속**: 공시 구간(1년 미만~6년 이상) 중간값 가중 **추정 평균**이다.
  단정적으로 말하지 말 것. "1년 미만 비율"이 높으면 이직이 잦다는 신호.
- **학급당 원아 수**: 적을수록 여유롭다. 공립 병설이 보통 사립보다 적다.
- **운영시간은 '문 여는 시간'이지 정규 수업 시간이 아니다.** 유치원 정규 교육과정은
  법정 1일 4~5시간이고, 공시된 07~18시 같은 시간대의 나머지는 전부 방과후·돌봄이다.
  병설·사립 공통이므로 운영시간만 보고 비교하면 안 된다.
- **병설유치원은 정규 수업일수가 법정 최소(180일)에 가깝다.** 초등학교 학사일정을 따라
  방학이 길기 때문이다. 사립은 보통 220~240일이라 **50일 가까이 차이 난다.**
  다만 방학 중에도 방과후과정은 운영되어 **'방과후 포함 운영일수'는 양쪽이 비슷하다**(230일 안팎).
  즉 병설은 "다닐 날이 적다"기보다 **"방학 기간을 방과후과정에 의존한다"**가 정확하다.
  그래서 병설을 볼 때는 **방과후 전담교사 인력**(방과후 과정 항목의 전담교사·강사 수)을
  함께 확인해야 한다. 방학 중 담임이 아닌 인력이 아이를 볼 가능성이 크기 때문이다.
- **혼합연령 학급**에도 해당 연령이 포함될 수 있으므로, 연령 필터에 안 걸린 곳도
  후보라면 `profile`로 확인한다.
- 공시는 연 2회(4월말·10월말경) 갱신되며 출력 상단에 `2026년 1차 공시`처럼 기준이 표시된다.
  **원서 접수(처음학교로, 입학 전해 11월) 직전에는 `--fresh`로 최신 자료를 다시 받는다.**
- `⚠ 공시 데이터 점검 중`은 교육부가 해당 항목을 잠근 상태다. 도구 문제가 아니니
  나중에 재시도하라고 안내한다.
- 사용자에게 답할 때는 표를 통째로 붙여넣지 말고 **질문에 맞게 추려서** 설명한다.

## 하지 말 것

- **원비·모집요강·경쟁률·통학구역은 이 API에 없다.** 지어내지 말고
  처음학교로(www.go-firstschool.go.kr)나 유치원 전화(출력에 있음)로 안내한다.
- 근속 평균 같은 추정치를 확정된 사실처럼 말하지 않는다.

## 문제 해결

- `인증키가 거부되었습니다` → `.env`의 `KINDER_API_KEY` 확인(따옴표·공백 금지)
- 결과 0곳 → 지역명 확인, `regions`로 저장된 지역 확인, `discover <시도>` 실행
- 경기도는 `discover 경기 --full` 필요(시 안에 구가 있는 구조, 5~10분)
- 그 밖의 증상은 도구 폴더의 `AGENTS.md` 문제 해결 표 참고
